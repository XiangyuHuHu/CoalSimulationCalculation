# 选煤厂工艺模拟计算系统

这是一个网页端静态原型，用于搭建选煤厂流程、拖拽设备、建立物流连线、调整设备参数，并按拓扑关系进行稳态质量平衡计算。

## 运行方式

可以直接打开 `index.html`。如果浏览器限制本地脚本，建议在当前目录启动本地服务：

```powershell
python -m http.server 5177
```

然后访问：

```text
http://localhost:5177/index.html
```

## 页面布局

- 左侧：入洗原煤参数、设备库、测试方案管理。
- 中间：流程画布、拓扑连线、全厂汇总指标。
- 右侧：选中设备参数、设备计算结果、物流计算结果、系统优化建议。

页面采用一屏式布局，右侧参数和表格区域内部滚动，尽量减少整页大范围滚动。

## 当前功能

- 设备库拖拽到画布新增节点。
- 画布节点可拖动调整位置。
- 从设备右侧不同物料出口拖到其他设备左侧入口，可以建立带物料类型的连线。
- 每条连线带箭头，箭头方向表示物流方向。
- 连线颜色按物流类型区分：精煤/产品、矸石/中煤、煤泥/底流、水路/介质等。
- 选中设备后，可以调整设备名称、设备参数、输出连线分配比例。
- 支持删除设备、删除输出连线。
- 支持测试方案管理：保存当前方案、新建测试、切换方案、删除方案、生成测试样例。
- 支持多出口设备模型，区分精煤、中煤、矸石、煤泥、水路、介质、滤饼、底流等物流。
- 顶部汇总从产品仓、尾煤仓、循环水池、介质桶实际收到的物流计算。
- 流程图连线和“物流计算结果”表会显示每条物流的流量、灰分等数据。
- 支持导出 CSV，导出内容包括全厂汇总、设备结果和物流结果。

## 测试方案

左侧“测试方案”区域用于保存和切换不同模拟工况。

- “保存当前方案”：保存当前入洗参数、设备位置、设备参数、连线、连线分配比例和当前选中设备。
- “新建测试”：先保存当前方案，再创建新的默认流程方案。
- “生成测试样例”：自动生成几组典型工况。
- “删除方案”：删除当前方案；如果只剩一个方案，则重置为默认测试方案。

内置测试样例包括：

- 样例A 低灰高产。
- 样例B 高灰原煤。
- 样例C 细煤泥偏高。
- 样例D 提质低密度。

方案保存在浏览器 `localStorage` 中，刷新页面后仍会保留。更换浏览器或清理浏览器数据后，本地方案会丢失。

## 计算逻辑位置

主要计算逻辑在 `app.js` 中：

- `calculate()`：按连线拓扑执行全流程计算。
- `computeNode()`：计算单个设备的输入、输出和结果。
- `modelNode()`：按设备类型生成多个出口物流。
- `transferLink()`：按连线物料类型和分配比例传递物流。
- `updateSummary()`：汇总产品仓、尾煤仓、循环水池、介质桶接收到的物流。
- `renderTable()`：输出设备计算结果。
- `renderLinkTable()`：输出每条连线的物流计算结果。
- `exportResults()`：导出全厂汇总、设备结果、物流结果。

## 拓扑质量平衡

系统把每条物流看成一个对象：

```text
stream = {
  mass: 质量流量 t/h,
  ash: 灰分 %,
  moisture: 水分 %,
  type: 物流类型
}
```

计算过程：

```text
1. 入洗原煤节点根据入洗量、灰分、水分生成原煤物流。
2. 系统按连线方向计算设备入料。
3. 多个上游进入同一设备时，质量相加，灰分和水分按质量加权平均。
4. 设备根据自身模型拆分成多个出口物流。
5. 同一出口如果连到多个下游，则按连线 split 的相对比例拆分。
6. 产品仓收到的物流汇总为精煤产品。
7. 尾煤仓收到的矸石、滤饼等物流汇总为矸石/尾煤。
8. 中煤物流单独汇总为中煤。
9. 循环水池收到的物流汇总为水路/损失。
10. 介质桶收到的物流汇总为介质回收。
```

每条连线包含：

```text
from: 上游设备
to: 下游设备
stream: 物料类型
split: 分配比例
```

例如同一个精煤出口分别连到两个下游，比例为 `70` 和 `30`，则该精煤出口按 70% 和 30% 分配。

## 设备模型

当前模型为稳态经验模型，适合功能验证和方案演示。

### 原煤筛分

```text
coarseRatio = efficiency * (1 - fineRatio * 0.55)
coarse = input * coarseRatio
fine = input - coarse
```

### 脱泥筛

```text
coarse = input * efficiency
slime = input * (1 - efficiency)
```

### 重介旋流器 / 块煤重介浅槽

```text
cleanYield = baseYield / 100 + (density - 1.4) * 0.24 - (inputAsh - 28) * 0.004

clean = input * cleanYield
middling = input * middlingYield
reject = input * rejectYield
slime = input * slimeYield
```

灰分估算：

```text
cleanAsh = inputAsh * 0.31 - (density - 1.4) * 7
rejectAsh = inputAsh + 22 + (density - 1.42) * 10
```

### 分级旋流器

```text
fineSlime = input * overflowRatio
coarseSlime = input * (1 - overflowRatio)
```

### 螺旋分选机

```text
effectiveYield = cleanYield * (0.92 + separation * 0.14)
clean = input * effectiveYield
reject = input - clean
```

### 浓缩机

```text
underflow = input * recovery
water = input * (1 - recovery)
```

### 压滤机

```text
cake = input * recovery
water = input * (1 - recovery)
```

### 离心机

```text
clean = input * solidRecovery
water = input * (1 - solidRecovery)
```

### 磁选机

```text
slime = input * 0.985
medium = input * 0.015
```

### 皮带机 / 筒仓 / 产品仓 / 尾煤仓

- 皮带机按可用率折算输送量。
- 筒仓、产品仓、尾煤仓主要做物流接收和传递。

## 参数含义

- `efficiency`：筛分、脱泥或设备效率。
- `density`：重介分选密度。
- `pressure`：旋流器压力。
- `cleanYield`：设定精煤产率。
- `ep`：可能偏差，当前保留为参数，尚未接入分配曲线。
- `mediumLoss`：介耗，当前保留为参数。
- `overflowRatio`：分级旋流器溢流比例。
- `separation`：螺旋分选效率。
- `flocculant`：浓缩机加药量，当前用于调参展示。
- `underflowSolid`：浓缩机底流浓度，当前用于调参展示。
- `cycle`：压滤周期，当前用于调参展示。
- `cakeMoisture`：压滤滤饼水分。
- `solidRecovery`：离心机固体回收率。
- `availability`：皮带机可用率。
- `capacity`：筒仓容量。
- `loadRate`：装车能力。

## 默认流程

默认流程包含：

- 入洗原煤
- 原煤筛分
- 末煤脱泥筛
- 块煤重介浅槽
- 末煤重介旋流器
- 磁选机
- 煤泥分级旋流器
- 螺旋分选机
- 浓缩机
- 压滤机
- 离心机
- 精煤皮带
- 精煤筒仓
- 精煤产品
- 矸石/尾煤
- 介质桶
- 循环水池

默认流程已接入精煤、尾煤、煤泥、水路和介质物流，顶部会显示质量平衡差。

## 仍需工程化校准的部分

当前版本已经可以按拓扑、多出口、多物料类型计算，但仍是原型模型。若用于生产决策，需要继续接入和校准：

- 浮沉组成、粒度组成、可选性曲线。
- 重介旋流器、浅槽、螺旋等设备的真实分配曲线和 Ep 曲线。
- 循环水、介质桶、补水、磁选回收、介耗的闭路平衡。
- 药剂消耗、浓缩沉降、压滤周期与含水率的动态模型。
- 在线密度计、灰分仪、流量计、皮带秤、化验数据和历史生产数据。
- 循环流程的迭代求解；当前拓扑更适合无环流程，有回流时需要引入收敛计算。
